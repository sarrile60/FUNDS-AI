# Traccia Fondi

AI-assisted fund-tracing platform for Italian victims of online financial scams.

## Stack

- **Backend**: FastAPI (Python 3.10+), MongoDB, Cloudinary, Resend
- **Frontend**: React 19, Tailwind CSS, Framer Motion
- **Hosting**: Ubuntu 22.04 + nginx + PM2 + Let's Encrypt

## Local development

```bash
# Backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# create backend/.env (see deploy.sh for the template)
uvicorn server:app --reload --port 8001

# Frontend
cd frontend
yarn install
# create frontend/.env with REACT_APP_BACKEND_URL=http://localhost:8001
yarn start
```

## Production deployment (one-shot)

On a fresh Ubuntu 22.04 VPS as root:

```bash
# 1. Pull the deploy script directly
curl -O https://raw.githubusercontent.com/YOUR_USER/traccia-fondi/main/deploy.sh
# 2. Edit GIT_REPO at the top
nano deploy.sh
# 3. Run
bash deploy.sh
```

The script installs nginx + Node + Python + PM2, clones this repo, builds the
frontend, starts the backend with PM2, configures nginx, and tries Let's Encrypt.

## Updating production

```bash
cd /var/www/traccia-fondi
git pull
bash /var/www/traccia-fondi/deploy.sh
```

The script is idempotent — re-running it just rebuilds + reloads.

## Admin

- URL:      `https://traccia-fondi.com/admin`
- Email:    set in `backend/.env` → `ADMIN_EMAIL`
- Password: set in `backend/.env` → `ADMIN_PASSWORD`

Rotate the admin password on first login of production.

## Environment variables

See `deploy.sh` for the full list:

| Var | Purpose |
|---|---|
| `MONGO_URL` | MongoDB connection string (Atlas in production) |
| `DB_NAME` | Mongo database name |
| `JWT_SECRET` | JWT signing secret (auto-generated by deploy.sh) |
| `CORS_ORIGINS` | Comma-separated allowed origins |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | Admin panel login |
| `CLOUDINARY_*` | Document storage |
| `RESEND_API_KEY` | Transactional email (recovery instructions, contact form) |
| `RESEND_FROM_*` / `RESEND_REPLY_TO` | Email sender addresses |

**Never commit `.env` files.** They are in `.gitignore`.
